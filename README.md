# Note Pilot

Hum low to dive. High to soar. 40 levels. One verb.

Open `note-pilot.html` in a browser (Chrome recommended). Allow the mic, or use arrow keys / W S.

## Tiers
- Easy 1-10 Dawn Staff
- Medium 11-20 Violet Hall
- Hard 21-30 Amber Pit
- Expert 31-40 Crimson Finale

Stars: 1 finish, 2 no front-hits, 3 also 45% PERFECT. Next level unlocks on 1 star.
